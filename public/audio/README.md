# Audio

- `sfx/` — Kenney "Interface Sounds" (CC0, public domain, no attribution required).
- `announcer/` — generated by `npm run announcer` via ElevenLabs "stadium voice".
  Every spoken number is fact-checked against the real stats at build time.
- `theme.mp3` — the BattleBots theme. Fades in on the first user interaction
  (browsers block autoplay before a gesture) and has a toggle bottom-right.
  `ThemeAudio` HEAD-checks it on mount and hides the control if it is missing or
  implausibly small, so a failed download degrades to silence rather than a dead
  button.
